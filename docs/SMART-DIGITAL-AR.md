# Smart Digital — توسعة المحادثات

70 مسارًا و322 صيغة سؤال مكتوبة مختلفة، بالإضافة إلى متابعة السؤال المختصر في سياق الشركة. العدّ يمثل صيغًا ومسارات محددة، وليس كل سؤال يمكن للعميل قوله، ولا عددًا من الإجابات المولدة بالذكاء الاصطناعي.

التغطية: المواقع التعريفية والمتاجر وصفحات الهبوط والموبايل واللغات والمحتوى والصور، الدومين والاستضافة والبريد والملكية والتسليم، التهيئة للبحث والقياس والحجز والدفع والشحن والمنتجات والمخزون وواتساب، إدارة الصفحات والمحتوى والإعلانات والميزانيات والنتائج والصلاحيات، التصميم والهوية والريلز والمونتاج، الأسعار والباقات والتجديد والتكاليف الإضافية والفصال والمقارنة والتقسيط، المواعيد والمراجعات والصيانة والأعطال والشكاوى والطلبات والمتابعة.

كل مسار له رد أول وتفاصيل إضافية. «فيدني أكتر» و«أعملها ليه» و«طب بكام» تستخدم المسار السابق عند توفر سياق Smart Digital لم يتجاوز 24 ساعة. تغيير الخدمة صراحة يغيّر المسار. السياق لا يأخذ معلومات الدليل الشامل أو شركة أخرى. التخزين في واتساب يظل داخل contact الخاص بالمرسل وحساب الشركة. معاينة اللوحة لا ترسل رسائل ولا تستهلك حصة، وسياقها ينتهي عند تغيير الشركة أو الحساب أو إعدادات المساعد.

التفعيل في الموظف والردود: اختار شركة Smart Digital الصحيحة ثم «تجهيز ردود Smart Digital للشركة المختارة». الزر يستبدل مكتبة الشركة المختارة بـ70 إجابة قابلة للتحرير. لا يغير باقي الشركات. الأسئلة المطابقة حرفيًا لرد معتمد حرره المالك تستخدم رده؛ القوالب الافتراضية تترك متابعة السياق فعالة.

لم تُعتمد أسعار أو مدد تنفيذ أو تفاصيل عروض تجارية جديدة. لا نستخدم 2499 أو أية أسعار محفوظة من عرض سابق تلقائيًا. أي عرض لازم يحدد السعر والمدة والمخرجات والتجديد والتكاليف الإضافية ويعتمده المسؤول. نوضح فائدة الخدمة حسب النشاط دون ضمان مبيعات أو ترتيب بحث أو توافر خدمة خارجية. ميزانية منصة الإعلان منفصلة عن أتعاب الإدارة. لا نؤكد دفعًا أو استردادًا أو إنشاء تذكرة أو حالة طلب بدون سجل معتمد.

الاختبار يشمل اختيار كل صيغة لمسارها، صيغًا طبيعية أخرى، متابعة السياق وتغييره وانتهائه، فصل الشركات والرد المعتمد، API المعاينة والإعدادات، ومسودات واتساب المعزولة لكل مرسل. اختبار Windows يجهّز القالب ويجرب متابعة «فيدني أكتر» من الواجهة المثبتة باستخدام Auth وFirestore وهميين. لا تعني هذه الاختبارات نجاح إرسال حقيقي إلى هاتف ولا جاهزية تجارية كاملة.
