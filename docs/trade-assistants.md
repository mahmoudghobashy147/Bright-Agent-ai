# Company trade replies

Khaled Design: 43 paths / 188 written question forms. Covers interior and facade design, supervision, finishing enquiries, materials, scope, revisions, quotations and support. Execution availability is collected for team confirmation, never promised.

Directory suppliers: 46 paths / 211 question forms. Covers listing, subscriptions, catalogues, product specifications, quantities, supply enquiries, delivery, invoicing and support. Existing eldalel profiles also route explicit supplier enquiries and their follow-ups here; category illustration requests keep the existing approved image flow.

Each preset replaces the selected company's saved reply library. Only owner/admin may save; preview/preset reads require membership. Profile and fresh contact context are isolated. Exact company-owned custom replies may override the corresponding dedicated preset.

The supplied knowledge pack marks supplier package numbers and Khaled offers as draft_requires_owner_review with enable_customer_quotes:false. These numbers are deliberately excluded from automatic replies. No stock, portfolio, delivery date, sale or booking is invented. This deterministic assistant handles common phrasing and clarification; it does not guarantee every possible question.

Validation includes all 399 aliases, spelling and multi-turn examples, protected preset/save/preview endpoints, quota-free previews, native inbox context isolation and the Windows install/start/UI smoke workflow. Windows UI uses Auth/Firestore emulators; it does not prove a fresh live phone pairing or customer delivery. No customer messages are sent by tests.
