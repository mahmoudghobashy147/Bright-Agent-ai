## قيد التحقق الخارجي

- GitHub Actions نجح في بناء NSIS وتثبيت التطبيق الناتج وتشغيل شاشة الإعداد على Windows runner. التشغيل الأول: https://github.com/mahmoudghobashy147/Bright-Agent-ai/actions/runs/41222617082 . يجري توسيع اختبار الواجهة إلى الشركات والإدارة باستخدام Auth ومخزن بيانات بديلين، وليس حسابات حقيقية.
- لم يتحقق تسجيل الدخول أو حفظ بيانات فعلية في bright-33420.
- لم يُستدع OpenAI الحقيقي، ولم يُربط رقم Meta اختبار، ولم تُرسل رسائل للعملاء.
- لم يُنفذ دفع Paymob sandbox حقيقي أو live، ولم تفحص دورة الاسترداد والتسوية أو الخصم الدوري. adapter الموجود sandbox فقط ولا يفعّل اشتراكًا.
- لم يختبر مثبت على جهاز المستخدم أو حساب Windows جديد فعليًا، ولا توجد شهادة توقيع بعد.
- لم يُحصر CRM الحقيقي أو تؤخذ نسخة أو تُستعد أو تُحذف بيانات.

## شروط التسليم النهائي

اختبار قبول مسجل على حسابات الاختبار المعتمدة: إنشاء شركة وموظف وإيقافه، فصل شركتين، محادثة الموقع، AI بمعلومات الشركة، نفاد الباقة، استقبال WhatsApp وتأخر الرسالة وتكرار webhook، مسودة وموافقة مستقلة لإرسال واحد لرقم الاختبار، Paymob sandbox ناجح وفاشل ومكرر واسترداد وربط فاتورة بالشركة، آلية تجديد/تعليق تجاري معتمدة، تثبيت وإعادة تشغيل وإزالة على Windows نظيف، ثم جهاز المستخدم. مطلوب كذلك اختبار تحميل وحماية موزعة للواجهة العامة ومراقبة وتنبيهات ونسخ احتياطية وخطة استعادة وسياسة خصوصية ومراجعة التبعيات والتوقيع قبل البيع.

لا يُحوّل نجاح CI هذه القائمة إلى اختبارات ربط حقيقية تلقائيًا.
